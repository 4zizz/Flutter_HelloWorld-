# Hello Flutter App

Aplikasi Flutter sederhana yang menampilkan teks **"Hello, Flutter"** di tengah layar dengan tema Material 3. Project ini dibuat sebagai latihan dasar pada mata kuliah Pemrograman Perangkat Bergerak (PPB).

## Fitur

- Menampilkan teks "Hello World!" di tengah layar
- `AppBar` dengan judul dan warna kustom
- Tema Material 3 dengan `ColorScheme.fromSeed` (warna dasar Deep Purple)
- Dapat dijalankan di Windows, Chrome, dan Edge
